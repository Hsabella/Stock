## 诊断：为什么 IC 达标但超额为负

1. **IC 是多空对称指标，长仓只能吃一半**。信号对"最差股"的识别能力（低彩票/高换手/追高股会跌）贡献了大量 IC，但纯多头 top30 无法做空它们，只能吃"最好股"那一半，而多头端区分度明显更弱（五分位报告里 Q5-Q4 价差远小于 Q1-Q2）。
2. **风格逆风**：v1 因子组合实质是"低波动 + 低换手 + 反转"风格，2024-10 之后的贝塔牛市里大市值动量股领涨，该风格系统性跑输；基准中证800 是市值加权大盘股指数，本身就是这轮行情的受益者。
3. **风格暴露失控**：等权 top30 相对市值加权基准有巨大的小市值/风格主动暴露，v1 没有做行业/市值中性化，超额收益被风格波动吞没（超额年化波动 14.4%，信息比率被压负）。
4. **2026H1 信号衰减**：样本外 IC 从 2023-2024 的 +0.075 衰减到 2026H1 的 0.00，需持续监控（可能是风格拥挤或数据期太近未消化）。

## 下一轮迭代方向（按预期收益排序，限时 4 周）

1. **行业+市值中性化选股**（组合构建问题，不是因子问题）：在每期截面上对预测分做行业/市值回归取残差再选 top N，或直接按行业配平——直接针对诊断 #3。
2. **多头端增强**：加入财报基本面因子（ROE、盈利增速，按公告日 PIT 对齐）和分析师预期修正——弥补多头端区分度不足。
3. **动量/反转情景切换**：用 regime（波动率/风格动量）在反转与动量因子间动态配权——针对 2024-10 后的风格切换。
4. **资金流因子入库**：em_fundflow 滚动累积满 1 年后作为二批因子评估。
5. **择时层用 off=0.7**：回撤改善与踏空代价的最优折中；A50/日韩早盘接入留实盘。
