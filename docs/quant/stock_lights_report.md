# 个股抄底红绿灯回测报告（左侧 vs 右侧 vs 大盘灯切换）

日期：2026-07-19 ｜ 代码：`quant/research/stock_lights.py` ｜ 明细：`results/quant/stock_lights_{events,trades}.csv`

## 问题

个股层只有止损线（卖）和排雷（避），缺"什么时候能买"。用户提出三个问题：
1. 深跌股怎么量化识别"能不能抄底"？
2. 左侧（跌的时候买）vs 右侧（等反转确认再买）哪个好？
3. 要不要按大环境切换风格（"大环境好就切左侧"）？

## 方法（要点）

- 事件式回测 2019-01 → 2026-07，qlib bin 前复权日线；T-1 收盘信号 → T 开盘成交。
- 两个池：`watch`（用户自选 51 只，**事后挑选有幸存者偏差，只做一致性参考**）+
  `neutral`（csi_union PIT 抽样 ~420 只，含已退市票，**主结论以此为准**）。
- setup 前置：距 120 日最高收盘 ≤ -25%/-35%/-45%（主参 -35%）。七条臂全部事件化
  （条件首穿才算信号）：S0 基准（见便宜就买）/ 左侧 L1 接刀、L6 超卖修复、L4 底背离 /
  右侧 R1 站回MA20、R3 走平站回、R4 低点翻转线。
- 出场：左臂 3×ATR 初始止损、右臂 -8%；追踪线锚"入场以来最高收盘-2×ATR"棘轮；
  60 日强评（右臂另测长持，无差异）。成本、板块级涨跌停（20cm）、一字板、卖出顺延、
  退市强平全建模。规则先注册再跑（详见脚本 docstring），设计经三视角独立评审修订，
  代码经前视偏差审计（时间对齐确认干净）。

## 结论

### H1：左侧完胜右侧（两池、三阈值、两时段方向一致）

中性池 thr=-35% 事件研究（ex20 = 20 日超额 vs 同股基线；t 值）：

| 臂 | n | 20日胜率 | ex20 | t |
|---|---|---|---|---|
| **L1 接刀** | 1312 | 60% | **+4.9%** | 11.2 |
| **L6 超卖修复** | 631 | 60% | **+4.9%** | 7.8 |
| S0 基准（见便宜就买） | 1745 | 54% | +2.3% | 6.8 |
| L4 底背离 | 810 | 51% | +1.6% | 3.0 |
| R4 低点翻转 | 2763 | 51% | +0.9% | 2.9 |
| R1 站回MA20 | 2924 | 50% | +0.6% | 2.2 |
| R3 走平站回 | 1320 | 47% | +0.2% | 0.4 |

- 左臂超额是右臂的 5-8 倍且相对 S0 有真增量；右臂全部**跑不赢 S0**。
- 机理：右侧入场价中位数比 20 日低点高 **11-15%**（确认溢价），超跌反弹场景里这笔
  溢价买不回来。左臂入场溢价 ≈ 0-5%。
- 交易仿真（含止损/成本）同序：L1 +3.6%/笔（pf 2.0）> L6 +3.0% > S0 +1.7% > R 臂 +0.3~0.6%。
- 分段：事件层 19-22 与 23-26 左臂几乎不衰减；交易层左臂 23-26 衰减约一半但仍正
  （+4.6%→+2.3%/笔）。深度越深越好（-45% 档 L1 ex20 +8.1%）。
- **证伪**：L4 底背离（watch 池 ex20 为负）、R3 走平约束（无增量）、恐慌放量承接
  （评审实测 r60 中位 +0.1%）——都别用。

### H2：灯色交互成立，但方向与直觉相反——"泥沙俱下才有黄金坑"

中证1000 灯 × 各臂（中性池 thr=-35%，ex20）：

| 臂 | 🔴红灯期 | 🟢绿灯期 |
|---|---|---|
| L1 接刀 | **+6.2%** (t=10.5) | +2.9% (t=4.6) |
| L6 超卖修复 | **+7.2%** (t=9.4) | -0.3% (t=-0.3) |
| R1/R4 | +2.7~+3.2% | **-2.3~-2.4%**（显著为负） |
| S0 基准 | +3.4% | +1.1% |

- 大盘（尤其中证1000）红灯期 = 系统性恐慌，个股深跌是"被大盘拖下水"，均值回归最猛。
- 大盘绿灯而个股独自深跌 = 大概率自身有问题（基本面雷/资金弃票），抄底无超额，
  右侧追入甚至显著为负。**"大环境好就切左侧"被证伪，正确读法是
  "大环境差时左侧才有肉；大环境好时的独跌票别碰"。**
- 用户设想的"绿灯左侧/红灯右侧"切换臂实测平庸（+1.7~2.0%/笔），不如纯左臂。
- hs300 灯方向相同、区分度略弱；watch 池同方向（L6 红灯期 win20 83%、ex20 +12.5%）。

### 落地规则（个股三态灯）

```
⚪ 未到setup   距120日高 > -35%                     → 与我无关
🟡 底部区观察  距120日高 ≤ -35%（或60日内曾达）      → 进观察，不动手
🟢 可入场      🟡 且 L6 超卖修复（首选）或 L1 接刀触发
              ├─ 中证1000 🔴 时：正常执行（历史超额最大的窗口）
              └─ 中证1000 🟢 时：降级为仅记录（独跌票无超额）
```

执行纪律（与回测同参）：次日开盘价入场，开盘触涨跌停/一字不追；单票半仓
（≤5% 总资产，因左侧止损宽）；止损 = 入场价 - 3×ATR14（约 -10~-14%），之后
"入场以来最高收盘-2×ATR"棘轮上移；60 个交易日未走出来强制重评；同票平仓后冷却 10 日。
总仓位仍受既有结构灯约束（科创50 红灯 = 新增减半）——个股灯管"这笔交易质量"，
结构灯管"账户风险预算"，两层各管各的。

## 已知局限

- 自选池数字（如 L6 ex20 +8.0%）含幸存者偏差，预期管理用中性池数字（+4.9%）。
- 红灯期信号成簇（2022 / 2024-01 / 2025H2），并发笔间相关，不是独立样本——
  并发新仓 ≤ 2-3 只（与卫星仓上限一致）。
- 交易层 23-26 衰减一半，需实盘对账：信号已具备落 signal_log 的条件（待接入晨报）。
- ST ±5% 档用一字板近似识别；灯滞后口径与晨报一致（入场日晨可见）。
